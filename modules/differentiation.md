# Differentiation — Anti-House-Clone

**Aufgabe:** Jede Site muss eine eigene Identität haben. Craft-Bar ≠ eine Palette.  
**Immer laden.** Lock ist nicht fertig ohne `## Differentiation` in `DESIGN-SYSTEM.md`.  
Adaptiert aus redesigner-jev `DIFFERENTIATION.md`.

---

## Das Problem

Läufe haben dieselbe Haut geshipped: void black + acid lime + magenta glass-rim + dual orbs + lime-dot kicker + Unbounded/Outfit + card-stack „rack“. Das ist ein **WhyNelo / Scalpo / CUTPOOL-Fingerprint**, kein Redesigner-Craft.

Klassen-Refs teilen *Entscheidungen* (Atmosphere, Instrument, Dichte) — nie eine recycelte Identität.

## Sibling-Ban (Package)

Nicht als Paket wiederverwenden (3+ zusammen = Fail):

- Canvas ≈ `#07070A`–`#08080A` + Acid `#C8FF3D` + Magenta `#FF2BD6`
- Glass-rim 2px lime→magenta auf jeder Card
- Soft lime orb + magenta orb als ganze Atmosphere
- Lime glowing status-dots als einziges Micro-Label
- Unbounded + Outfit + IBM Plex Mono als einziges Type-Lock
- Pool Rack / Drop Rack / Card-Swipe-Stack als Default-Hero für fremde Produkte

Streetwear-Tool-Skins dürfen das Paket **nur** wenn der User die Linie verlangt. Portfolio, Agency, SaaS, Gastro müssen auf **jeder** Achse eine andere Zeile wählen.

---

## Forced variety (beim Lock)

1. **Lightness:** dark-only / light / ink-on-cream / split  
2. **Accent count:** mono / +marker / editorial ink (kein Neon)  
3. **Geometry:** soft radius / sharp 4–8px / mixed with intent  
4. **Density:** still / ausgestattet / voll — zum Inhalt  
5. **Refero + Godly:** nicht dieselben 2 Styles/URLs wie letztes Mal; Namen loggen

## Tests

**Sibling (Pflicht):** letzte 1–2 Skill-Sites daneben, 25 % Zoom:

> Unterscheide ich die Heroes in unter 2 Sekunden **ohne** Logo?

Nein → ≥3 Achsen ändern, zurück zu Phase 1/2.

**Reskin:** Name+Akzent tauschen → Konzept muss halten (gutes Produkt).  
**Differentiation:** Name behalten, Sibling vergleichen → darf **kein** Theme-Switcher auf demselben Template sein.

Beide müssen passen.
