# Godly DNA — Forschung / Research

**Aufgabe:** Echte, kuratierte Sites lesen; DNA extrahieren; auf diese Marke remappen.  
**Phase:** 2 (hart)  
**Quelle:** https://godly.design/websites/  
**Artefakt:** `GODLY-DNA.md`  
**Prompt:** `prompts/02-godly.md`

Ergänzend (nicht statt Godly): `modules/refero.md`, Klasse-Sites in `redesigner-lol.md`.

---

## Warum Pflicht

Pro Max + Taste erzeugen einen *Plan*. Godly zwingt den Plan gegen **gebaute** Sites. Ohne diese Phase bleibt der Lock ein Modell-Prior.

---

## Auswahl

1. Godly `/websites/` öffnen (Browse, nicht nur Memory).
2. 1–3 Sites wählen, die zum **Brief** passen (Branche, Dichte, Licht, Typo-Rolle) — nicht die virale Karte der Woche.
3. Live-URL der Site öffnen, nicht nur das Godly-Thumbnail.
4. Screenshot Desktop-Hero + eine Mid-Section + Mobile wenn möglich.

Ablehnen: Pixel-Clone, Token-Steal, Copy-Steal, Logo-Steal.

---

## Extrakt (pro URL)

Schreib Werte, keine Adjektive allein:

| Feld | Was messen |
|------|------------|
| Type scale | Display / H1 / H2 / Body / Label — ungefähre px oder clamp, Tracking, Gewicht |
| Measure | ch / max-width der Textspalte |
| Spacing rhythm | Section-Padding-Folge, nicht „großzügig“ |
| Grid | Verhältnis (7/5, Marginalie, Raster sichtbar?) |
| Hierarchy | Was ist primär im ersten Viewport? |
| Material | Foto / Mesh / flach / Papier / Objekt |
| Motion | Ein benanntes Muster (oder none) + ungefähres Timing |
| CTA language | Form, Platzierung, sticky? |
| Density | still / möbliert / voll — in eigenen Worten |
| Color roles | Canvas, Ink, ein Akzent — **remap**, Hexes nicht übernehmen außer Brand-Overlap |

---

## Remap-Regeln

- DNA = Verhältnisse und Rollen. Hexes, Wordmark, Fotos, Copy bleiben beim Original.
- Godly-Typo-Paar nur wenn lizenziert **und** zum Brief; sonst Äquivalent self-hosten.
- Wenn alle drei Referenzen dieselbe Hero-Formel haben (Badge + H1 + Dual-CTA): **andere** Sites suchen oder bewusst gegen die Formel locken.
- Sibling-Test: die neue Site darf nicht wie „Godly-Skin #14“ aussehen.

---

## Output-Check

`GODLY-DNA.md` enthält:

- gewählte URL(s) + warum
- Extrakt-Tabelle
- `## Remap` — was in `DESIGN-SYSTEM.md` landet
- `## Discard` — was bewusst nicht kommt

Ohne URLs oder nur „inspiriert von Godly“ = Phase fehlgeschlagen, zurück.
