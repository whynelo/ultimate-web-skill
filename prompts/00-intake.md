# 00 — Deep Intake / Tiefen-Briefing

**Phase 0 (hart).** Nur Fragen + Artefakte. Kein DESIGN-SYSTEM, keine Komponenten, keine Seite.

Modul: `modules/intake.md` · Templates: `templates/BRIEF.md`, `templates/INTAKE.json`  
Legal immer mitdenken: `modules/legal-security.md`.

---

STOP. Du baust nichts. Du briefst.

1. Lies vorhandene User-Nachrichten, URLs, Dateien. Wiederhole keine bekannte Tatsache als Frage.
2. Mode 1 / 2 / 3 vorschlagen und bestätigen. Mode 2: Audit-Tabelle Keep/Improve/Drop/Replace anlegen — nichts erfinden.
3. Typ A–E und Legal class A–E vorschlagen.
4. Fragen in Runden (5–8). Pflicht: wer zahlt, Angebote als Nomen, eine Handlung, Sprache+Anrede, NAP oder ehrlicher Platzhalter, Assets-Provenienz.
5. Design-Read: eine Zeile („Reading this as: …“).
6. Schreibe `BRIEF.md` (DE wenn Brief DE) und `INTAKE.json`. Keine TBD-Pflichtfelder ohne `unknown` + Grund.
7. Nie: HRB, USt, Reviews, „seit …“, Partnerlogos, Fake-Metriken.

Dieser Text = Phase 0. Keine Quelle, kein Godly, kein Watermelon.

STOP. Nächster Prompt: `prompts/01-design-intelligence.md`.
